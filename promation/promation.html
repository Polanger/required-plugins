🎯 What is Polanger RP?

Polanger RP is a modern, lightweight plugin dependency manager for WordPress theme developers. Single file, zero dependencies, built entirely on native WordPress APIs. The perfect TGMPA alternative.

📦

Single File

Just one PHP file (~1000 lines). Copy to your theme and start using immediately.

⚡

Zero Dependencies

No external libraries required. Uses native WordPress APIs only.

🔄

Update System

Version-based update detection with one-click updates.

🚀

Bulk Install

Queue-based system with no timeout issues.

🌐

External Sources

Install plugins from CDN or remote servers via HTTPS.

🔐

License Ready

Hook-based architecture for premium theme license integration.

📂 Four Source Types

Polanger RP supports four different plugin source types to cover all use cases:

🌍

WordPress.org

Install plugins directly from the official WordPress.org repository.

source => 'wordpress'
📁

Bundled

Include plugin ZIP files within your theme package.

source => '/path/to/plugin.zip'
🌐

External

Download plugins from CDN or remote servers via HTTPS.

source => 'https://cdn.example.com/plugin.zip'
🔐

License

Integrate your own license API for premium plugin downloads.

source => 'license'

⚙️ Installation (3 Steps)

1

Download the File

Download polanger-required-plugins.php from GitHub:

Download from GitHub
2

Copy to Your Theme

Copy the file to your theme's lib folder:

your-theme/
├── functions.php
└── lib/
    └── polanger-required-plugins.php
3

Add to functions.php

Add the following code to your theme's functions.php:

<?php
// Load Polanger RP library
require_once get_template_directory() . '/lib/polanger-required-plugins.php';

// Define required plugins
polanger_require_plugins([
    'elementor',
    'contact-form-7',
    'woocommerce',
]);

💻 Usage Examples

Simple Usage

WordPress.org plugins only:

polanger_require_plugins([
    'elementor',
    'woocommerce',
    'contact-form-7',
]);

Shorthand

Shorter syntax:

polanger_require('elementor', 'woocommerce', 'contact-form-7');

Bundled (Theme) Plugin

Plugin included as ZIP in theme:

polanger_require_plugins([
    'elementor',
    [
        'slug'   => 'theme-core',
        'name'   => 'Theme Core Plugin',
        'source' => get_template_directory() . '/plugins/theme-core.zip',
    ],
]);

Required vs Recommended

required => true for required, required => false for recommended:

polanger_require_plugins([
    [
        'slug'     => 'elementor',
        'required' => true,  // Required
    ],
    [
        'slug'     => 'contact-form-7',
        'required' => false, // Recommended
    ],
]);

Version Control (Update System)

Require a specific version:

polanger_require_plugins([
    [
        'slug'    => 'theme-core',
        'name'    => 'Theme Core Plugin',
        'source'  => get_template_directory() . '/plugins/theme-core.zip',
        'version' => '2.0.0', // This version is required
    ],
]);

If installed version is 1.0.0, it will show "Update Available (1.0.0 → 2.0.0)".

NEW in v4.0

External Plugin (CDN/Remote Server)

Install plugins from external HTTPS URLs:

polanger_require_plugins([
    [
        'slug'    => 'pro-addon',
        'name'    => 'Pro Addon',
        'source'  => 'https://cdn.example.com/plugins/pro-addon.zip',
        'version' => '2.0.0',
    ],
], [
    'allowed_domains' => ['cdn.example.com'], // Security whitelist
]);

Security: External sources require HTTPS and .zip extension. Use allowed_domains to whitelist trusted domains.

NEW in v4.0

License-Protected Plugin (Premium Themes)

Integrate your own license API for premium plugin downloads:

// Step 1: Register plugin with 'license' source
polanger_require_plugins([
    [
        'slug'   => 'theme-pro-features',
        'name'   => 'Theme Pro Features',
        'source' => 'license',
    ],
]);

// Step 2: Add your license handler
add_filter('polanger_license_download_url', function($url, $plugin) {
    $response = wp_remote_post('https://api.yourtheme.com/download', [
        'body' => [
            'license' => get_option('theme_license_key'),
            'plugin'  => $plugin['slug'],
            'domain'  => home_url(),
        ]
    ]);
    $data = json_decode(wp_remote_retrieve_body($response), true);
    return $data['download_url'] ?? new WP_Error('invalid', 'License invalid');
}, 10, 2);

This architecture allows integration with any license system (Envato, EDD, WooCommerce, custom) without modifying the library.

Parameters

Plugin Parameters

Parameter Type Default Description
slug string (required) Plugin slug (e.g., 'elementor')
name string from slug Plugin name (auto-generated)
source string 'wordpress' 'wordpress', file path, HTTPS URL, or 'license'
required bool true true=required, false=recommended
version string '' Minimum required version

Configuration Options

Option Default Description
id 'polanger' Unique ID (for dismiss)
menu_title 'Install Plugins' Menu title
menu_slug 'polanger-install-plugins' Menu URL slug
parent_slug 'themes.php' Parent menu (themes.php = Appearance)
capability 'install_plugins' Required capability
allowed_domains [] Whitelist for external source domains

🌍 Real World Examples

Example functions.php for an e-commerce theme:

<?php
/**
 * Theme Functions
 */

// Polanger RP
require_once get_template_directory() . '/lib/polanger-required-plugins.php';

// Define required plugins
add_action( 'after_setup_theme', function() {
    polanger_require_plugins([
        // Required for e-commerce
        [
            'slug'     => 'woocommerce',
            'name'     => 'WooCommerce',
            'required' => true,
        ],
        // Required for page builder
        [
            'slug'     => 'elementor',
            'name'     => 'Elementor',
            'required' => true,
        ],
        // Theme core plugin (bundled)
        [
            'slug'     => 'theme-starter-core',
            'name'     => 'Theme Starter Core',
            'source'   => get_template_directory() . '/plugins/theme-starter-core.zip',
            'required' => true,
            'version'  => '1.5.0',
        ],
        // Recommended for SEO
        [
            'slug'     => 'wordpress-seo',
            'name'     => 'Yoast SEO',
            'required' => false,
        ],
        // Recommended for contact forms
        [
            'slug'     => 'contact-form-7',
            'name'     => 'Contact Form 7',
            'required' => false,
        ],
    ], [
        'id'         => 'theme-starter',
        'menu_title' => __( 'Theme Plugins', 'theme-starter' ),
        'menu_slug'  => 'theme-starter-plugins',
    ]);
});

Preparing Bundled Plugins

1

ZIP the Plugin Folder

theme-core/
└── theme-core.php

→ theme-core.zip
2

Place in Theme

your-theme/
└── plugins/
    └── theme-core.zip
3

Define in functions.php

[
    'slug'   => 'theme-core',
    'source' => get_template_directory() . '/plugins/theme-core.zip',
]
Important: The ZIP file must contain the plugin folder!
Correct: theme-core.zip → theme-core/ → theme-core.php
Wrong: theme-core.zip → theme-core.php

Frequently Asked Questions

Does it support Multisite?

Yes, it works with WordPress multisite.

Can I use it in a child theme?

Yes, use get_stylesheet_directory() instead.

Is JavaScript required?

No, core functionality doesn't require JS. Only minimal JS for "Select All" checkbox.

Is it compatible with PHP 8?

Yes, tested with PHP 7.4, 8.0, 8.1, 8.2.

Where does the plugin list appear?

Appearance > Install Plugins (or your configured parent_slug)

How do I dismiss the notice?

Required plugins can't be dismissed. Recommended plugins can be dismissed by clicking X.
